# NETTPLUS (sitio informativo)

Sitio estático basado en la Especificación definida v3.0. Se abre con `index.html`.

```
nettplus-info/
├── index.html              Inicio: resumen, roles y cómo funciona
├── secciones/
│   ├── requerimientos.html Requerimientos funcionales y no funcionales
│   ├── pantallas.html      Las 10 pantallas y los permisos por rol
│   ├── tecnologia.html     Stack tecnológico
│   ├── datos.html          Modelo de datos (9 tablas)
│   └── decisiones.html     Decisiones de cierre
├── css/
│   └── estilos.css         Todos los estilos (8 secciones comentadas)
├── imagenes/
│   └── logo.svg
└── README.md
```

Para cambiar los colores, edita las variables de `:root` al inicio de `css/estilos.css`.
